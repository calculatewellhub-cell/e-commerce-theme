# Aurelia — universal WooCommerce block theme + Aurelia Commerce plugin

Work in progress. See the milestone plan below; full English and Hindi documentation lands with milestone 6.

## Milestones
1. Theme foundation and design system (theme.json tokens, 7 style variations, dark mode, patterns) ✅
2. WooCommerce templates (shop, product, cart, checkout, order confirmation, account styling) ✅
3. Plugin features (WhatsApp ordering, UPI QR payments, AI concierge, 3D viewer, video studio, social posting, analytics, SEO/AIO, shop UX)
4. Demo import and setup wizard
5. Testing and polish (PHPCS, Playwright screenshots, accessibility, performance)
6. Docs, translations (EN + Hindi) and release build
