A premium, universal WooCommerce block theme with seven style variations, dark mode and more than twenty store patterns.

== Description ==

Aurelia is a Full Site Editing WooCommerce theme for any kind of shop — jewellery, fashion, electronics, beauty, grocery or home décor. Switch the entire look from Appearance → Editor → Styles:

* Luxe — emerald and gold with Cormorant Garamond and Jost (default)
* Noir — the Luxe palette in permanent dark mode
* Fashion — editorial monochrome and blush with Bodoni Moda and Manrope
* Electronics — electric blue with Space Grotesk and Inter
* Beauty — plum and rose with Fraunces and DM Sans
* Grocery — leaf green and citrus with Outfit and Nunito Sans
* Minimal — black and white with Inter

Every colour, font, radius and spacing value is a theme.json token, so all patterns and templates adapt to the chosen style. Visitors can switch between light and dark mode (the theme also follows the device setting).

Included templates: home, blog, single post, pages (default, wide, no title, landing), archive, search, 404, shop, product category/tag/attribute, product search, single product, cart, checkout and order confirmation.

Included patterns: hero with 3D stage, full-width image hero, split hero, scrolling marquee, 3D category tiles, new arrivals and on-sale carousels, best sellers and featured grids, promo banners, countdown sale, testimonials, FAQ, brand logos, Instagram-style gallery, newsletter, trust badges, "how to order on WhatsApp", "why shop with us", and full Home, About and Contact page layouts.

The theme contains presentation only. Install the free Aurelia Commerce plugin for WhatsApp ordering, the AI shopping concierge, the 3D product viewer, wishlist/compare/quick view, analytics, SEO structured data and one-click demo content. The theme works fully without it.

== Installation ==

1. In your admin area go to Appearance → Themes → Add New → Upload Theme.
2. Choose aurelia.zip and click Install Now, then Activate.
3. Install WooCommerce (and optionally Aurelia Commerce).
4. Go to Appearance → Editor → Styles to pick a style variation.

== Frequently Asked Questions ==

= How do I change the colours or fonts? =
Appearance → Editor → Styles. Choose a variation, then fine-tune Colors and Typography.

= How do I make the header menu a mega menu? =
Select the Navigation block in the header, open the Styles panel and choose "Mega menu". Nested submenus become columns.

= How do I set the countdown end date? =
Select the Custom HTML block inside the Countdown sale pattern and set data-end, for example data-end="2026-12-31T23:59:59+05:30". Leave it empty for a daily deal that ends at midnight.
